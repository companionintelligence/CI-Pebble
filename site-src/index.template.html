Setup in four steps.

You need a running {{products.memory.name}} and a Pebble.

  1. Create an API key

    In {{products.memory.name}}, open Settings, API keys, and create one with the memory scope. Test it from any terminal:

    curl -X POST https://your-memory.example/api/memory/recall \
  -H "x-api-key: YOUR_KEY" -H "Content-Type: application/json" \
  -d '{"query": "what happened recently?", "maxResults": 3}'

  2. Install the watch app

    Open the Companion Memory listing in the Pebble phone app and install it on your watch. Prefer to build it yourself? The source is public at CI-Pebble. In CloudPebble, import the repository and press Compile. Or locally:

    uv tool install pebble-tool
pebble sdk install latest
npm run build

  3. Try it in the emulator

    No watch to hand? Run pebble install --emulator basalt after a local build to see it first.

  4. Connect your Memory

    In the Pebble phone app, open Companion Memory settings. Enter your Memory URL and the key. Save, and the app checks the connection and tells you what works.

Give the key only what it needs.

{{products.memory.name}} denies a scoped key on any route that does not name its scope. That is a good default, and it decides what each feature can do today.

Your data. Your Memory. Nothing in between.

  • Requests go from your phone straight to the Memory URL you enter. There is no relay and no account.
  • The API key lives on your phone. The settings page is a local page, so the key never touches a web server.
  • Location sync is off until you turn it on, and it only ever goes to your Memory.
  • The app has no analytics and no third party. One exception is outside our hands: if you speak a question, Pebble Dictation is a cloud speech service, so that audio goes to the speech service your Pebble platform uses. Picking a listed question sends no audio anywhere.
  • This website, not the app, uses Google Analytics and Cloudflare Web Analytics. See the {{company.brand}} privacy policy.
