Companion Pebble

Your Digital Memory, on your wrist

A Pebble smartwatch app that talks to your own self-hosted Companion Intelligence (CI) Digital Memory server — nothing else.

Get the app Setup guide

How it connects

The watch never talks to the network directly. It sends a small request over Bluetooth to a companion app on your phone, which makes one authenticated call to your CI-Server appliance and relays the answer back.

Your CI-Serverself-hosted

That's the whole path. The app never reaches Ollama or CI-Hub directly (dashed, in red above) — those are CI-Server's own concern, reached (if at all) through CI-Server itself.

Setup

  1. Install the Pebble SDK and confirm it works: 
    pebble sdk install latest
pebble --version
  2. On your CI-Server appliance, create an API key under Settings → API Keys with the memory scope enabled.
  3. Build and install the watch app: 
    pebble build
pebble install --phone <PHONE_IP> --logs
  4. On the Pebble phone app, open CI Memory's settings and enter your CI-Server URL and the API key from step 2.

Full setup, troubleshooting, and the underlying API contract live in the project README.

Privacy

  • Your memory data stays on hardware you own and control.
  • Phone → CI-Server calls are HTTPS, authenticated with an API key scoped to what this app needs.
  • Passive location samples are only sent when your phone grants permission, and only to your own CI-Server.
  • This app has no third-party analytics and no connection to any service other than the CI-Server you configure.
